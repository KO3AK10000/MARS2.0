# Онлайн таймер гри

Це окремий варіант таймера, який не залежить від однієї Wi-Fi мережі. Його треба запустити на публічному сервері, після чого ведучий і гравці відкриватимуть одну інтернет-адресу.

## Як працює

1. Сервер зберігає єдиний стан гри.
2. Ведучий відкриває головну сторінку.
3. Гравці сканують QR-коди зі сторінки ведучого.
4. Усі таймери синхронізуються через інтернет.

## Локальна перевірка

У папці `game-timer-online` виконайте:

```powershell
npm install
npm start
```

Потім відкрийте:

```text
http://localhost:5173
```

## Запуск в інтернеті

Цей проєкт можна розмістити на будь-якому сервісі, який запускає Node.js:

- Render
- Railway
- Fly.io
- VPS-сервер
- власний сервер з Node.js

Для більшості сервісів налаштування такі:

```text
Build command: npm install
Start command: npm start
Node version: 18 або новіша
```

Сервер сам використовує змінну `PORT`, яку видає хостинг. Якщо запускати локально, буде порт `5173`.

## Адреси

Сторінка ведучого:

```text
https://ВАША-АДРЕСА
```

Сторінки гравців створюються автоматично QR-кодами на сторінці ведучого.

Короткі адреси гравців:

```text
https://ВАША-АДРЕСА/player.html?p=0
https://ВАША-АДРЕСА/player.html?p=1
https://ВАША-АДРЕСА/player.html?p=2
https://ВАША-АДРЕСА/player.html?p=3
https://ВАША-АДРЕСА/player.html?p=4
```

## Важливо

Поки що це один спільний стіл гри на один запущений сервер. Тобто якщо відкрити цю саму адресу двома різними компаніями одночасно, вони керуватимуть однією грою. Для кількох паралельних ігор треба додати кімнати з кодом гри.

## Файли

- `server.js` - сервер і синхронізація.
- `index.html` - сторінка ведучого.
- `script.js` - логіка сторінки ведучого.
- `player.html` - сторінка гравця.
- `player.js` - логіка сторінки гравця.
- `styles.css` - оформлення.
