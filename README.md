# Таймер гри

У проєкті є дві версії інтерфейсу:

- сторінка ведучого: `http://localhost:5173`
- сторінка гравця на телефоні: `http://АДРЕСА-НОУТБУКА:5173/player.html?name=ІМ'Я`

Стан гри зберігається на ноутбуці ведучого в `server.js`, тому всі відкриті пристрої бачать один і той самий синхронізований таймер.

## Запуск на ноутбуці ведучого

1. Відкрийте PowerShell у папці проєкту.
2. Виконайте команду:

```powershell
node server.js
```

3. На ноутбуці відкрийте:

```text
http://localhost:5173
```

4. У PowerShell після запуску з'являться адреси для телефонів, наприклад:

```text
Phones in the same Wi-Fi can open: http://192.168.1.25:5173
```

5. Телефони мають бути підключені до тієї самої Wi-Fi мережі, що й ноутбук.
6. На сторінці ведучого внизу є QR-коди для телефонів кожного гравця.

## Як підключити телефони

На телефоні кожного гравця відкрийте камеру й наведіть її на QR-код з його іменем. Також можна вручну відкрити короткі посилання:

```text
http://АДРЕСА-НОУТБУКА:5173/player.html?id=ЮРКО
http://АДРЕСА-НОУТБУКА:5173/player.html?id=РАЗБІК
http://АДРЕСА-НОУТБУКА:5173/player.html?id=ВАЛЄРЧИК
http://АДРЕСА-НОУТБУКА:5173/player.html?id=ДІДУСИК
http://АДРЕСА-НОУТБУКА:5173/player.html?id=МАРКУСИК
```

Замість `АДРЕСА-НОУТБУКА` треба підставити адресу, яку покаже PowerShell після запуску сервера.

## Що бачить ведучий

Ведучий бачить:

- усі 5 таймерів;
- випадаючі списки імен для зміни порядку;
- кнопки `старт`, `стоп`, `готов`, `ПАС`, `+ 1 хв`, `- 1 хв` для кожного гравця;
- нижні кнопки `ПОЧАТОК`, `СТОП`, `ДРАФТ`, `NEXT`;
- номер покоління;
- посилання для телефонів.

## Що бачить гравець на телефоні

Гравець бачить:

- своє ім'я;
- свій таймер;
- таймер `ПОЧАТОК`;
- таймер `ДРАФТ`;
- номер покоління;
- кнопки `ГОТОВ`, `ПАС`, `NEXT`.

Гравець не може сам вимкнути `ПАС`. Це може зробити ведучий кнопкою `ПАС` біля його таймера, або `ПАС` автоматично скинеться після нового `ДРАФТУ`.

## Основні правила роботи

1. `ПОЧАТОК` запускає 10-хвилинний таймер на кнопці. Повторне натискання під час відліку скасовує його.
2. Коли `ПОЧАТОК` закінчується, запускаються таймери всіх гравців, які не натиснули `ГОТОВ` і не мають `ПАС`.
3. `ДРАФТ` міняє порядок гравців: перший переходить у кінець, покоління збільшується на 1, `ГОТОВ` і `ПАС` скидаються, запускається 3-хвилинний драфтовий таймер.
4. Коли `ДРАФТ` закінчується, запускаються таймери всіх гравців, які не натиснули `ГОТОВ`.
5. `СТОП` зупиняє всі таймери гравців, скидає всі `ГОТОВ` і робить так, що наступний `NEXT` запускає першого гравця.
6. `NEXT` зупиняє поточного активного гравця і запускає наступного, пропускаючи гравців із `ПАС`.
7. Пробіл на клавіатурі ведучого робить те саме, що `NEXT`.
8. Коли час гравця доходить до нуля, таймер продовжує рахувати з мінусом.

## Звук

Звуковий сигнал є:

- коли закінчується `ПОЧАТОК`;
- коли закінчується `ДРАФТ`;
- коли на таймері гравця вперше стає менше 10 хвилин.

На деяких телефонах браузер дозволяє звук тільки після першого натискання на сторінці. Тому перед грою кожному гравцю варто один раз натиснути будь-яку кнопку на своїй сторінці.
